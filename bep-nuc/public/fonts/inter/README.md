# Inter (self-hosted)

Source: https://github.com/rsms/inter
Font: https://raw.githubusercontent.com/rsms/inter/master/docs/font-files/InterVariable.woff2
License: SIL Open Font License 1.1; see LICENSE.txt.
Retrieved: 2026-10-18.

The application serves this variable font locally with font-display: swap and Arial as fallback. No runtime font CDN requests. The font cmap was checked for the Vietnamese UI sample and the Vietnamese dong sign; visual rendering remains a browser QA step.
